# SoundSplit Feedback

Este repositorio público es solo para sugerencias y reportes de errores de SoundSplit. No contiene el código de la aplicación.

## Cómo enviar un comentario

Abre **Issues** y elige **Reportar un error** o **Enviar una sugerencia**. Los comentarios publicados son visibles para cualquiera. No incluyas información personal, nombres de procesos o dispositivos, grabaciones de audio, registros ni otros datos privados.

La aplicación no adjunta diagnósticos automáticamente. Tú decides qué escribir y enviar.

## English

This public repository is only for SoundSplit suggestions and bug reports. It does not contain the app's source code. Open **Issues** and choose **Report a bug** or **Suggest an improvement**. Published reports are public. Do not include personal information, process or device names, audio recordings, logs, or other private data. The app does not attach diagnostics automatically.
